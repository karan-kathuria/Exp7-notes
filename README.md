NoteBook — React Notes App

A simple and responsive notes application built using React and Vite.

Features

- Create notes with a title and description
- Edit existing notes
- Delete notes with confirmation
- Save notes in browser local storage
- Responsive design for different screen sizes

Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

How to Run Locally

1. Install Node.js.
2. Open the project folder in VS Code.
3. Run "npm install".
4. Run "npm run dev".
5. Open the local URL shown in the terminal.
